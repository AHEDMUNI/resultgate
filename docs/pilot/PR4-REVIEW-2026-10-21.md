## Cleanup and replay review

The repaired helper resolves browser IDs by agent session ID, validates every
ownership binding and complete item count before mutation, rejects duplicate IDs,
stops only active browsers and verifies returned ID, agent ID and stopped status.
Empty/incomplete listings fail closed. Browser IDs are distinct from agent IDs in
tests. No browser endpoint or returned CDP URL becomes an arbitrary network target.

The SQLite insert reserves the sole dispatch slot before POST; an existing record,
including an ambiguous create result, is never automatically submitted again.
Local restart uses the same durable record. This guarantee is per journal, not
across unrelated databases/machines. The historical Actions journal was ephemeral;
the count guard, one provider run and now-disabled workflow establish this test's
non-duplication, not a reusable global execution service.

Two hardening fixes made during this review:

1. Replace generic route matching with explicit HTTP method/path/body combinations.
   Unexpected DELETE, POST, PATCH, GET-cancel and unexpected GET-body operations
   fail before DNS/network access.
2. Return a nonzero CLI exit code when `run`/`reconcile` is unverified or browser
   stop is unconfirmed. Structured output remains available and the database closes.
