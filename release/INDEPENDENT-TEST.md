# Voluntary independent acceptance form (not a completed test)

Do not send private source text, prompts, URLs, API keys or full logs.

1. Which public directory/search led you to the exact ResultGate listing? Provide the public listing URL.
2. What public package version did you install? OS and Python major/minor version are enough.
3. Did your MCP client discover check_extraction and check_citations?
4. Did the documented positive, negative and missing-evidence samples produce pass, fail and unknown?
5. Have you used it for an actual task outside this project's development/testing? A yes/no and non-confidential task category is sufficient. Internal tests do not count as external use.
6. Optional: enable local measurement and inspect the exported aggregate summary. Share only if you consent; it includes a random persistent installation identifier and dates/counts. No automatic upload occurs. If posted publicly, your account name will be visible alongside it; do not assume anonymity.
7. On a later date, export again if you choose. Returning use is measured separately from downloads and first-run tests. We reconcile repeated summaries rather than counting them twice.

Independence and usefulness are reviewed; a self-reported identifier or a machine-generated summary alone is not proof. No payment or marketing action is required. This form does not claim anyone has already participated.
