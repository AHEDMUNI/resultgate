# Third-party components

ResultGate uses the official MCP Python SDK, Starlette, Pydantic and Uvicorn, plus their declared dependencies. jsonschema is used for development comparisons. These dependencies retain their own licenses and notices from their distributions. No crawler/validator competitor source code has been copied into this package.

requirements-tested.txt is the reviewed dependency-version snapshot, not a cryptographic supply-chain guarantee. Audit tools are development-only and are not runtime dependencies. Release artifacts must be built from the reviewed source and their SHA-256 values recorded. The future public namespace and package registry ownership must be verified before publishing.
