Connect to the existing pilot

Endpoint: https://agents.allubiyerbamate.com/mcp
Transport: Streamable HTTP. Request an individual pilot credential through support; issuance is manual. No shared public token or self-service OAuth is available.

Your MCP client must set Authorization: Bearer <issued credential> and accept both application/json and text/event-stream. Keep the token in your client's secret store, never a URL, screenshot or public issue. An anonymous HTTP 401 is expected.

Current hosted tools

  • search_providers: simulation registry listings; no claim of approved commercial sellers.
  • create_simulation_task: a simulated task only.
  • get_simulation_task: read your permitted simulation task.

Initialize your MCP session and call tools/list to confirm the actual capabilities. Commercial Checkout tools in draft PR #12 are not exposed by this hosted endpoint.
